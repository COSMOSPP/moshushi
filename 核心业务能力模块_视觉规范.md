# 核心业务能力模块视觉规范

> 适用于「模数师数字平台」官网首页「核心业务能力 / 五大业务能力」模块。
>
> 视觉关键词：**年轻化、数字化、AI、专业、轻科技、企业级、人才能力体系**

------------------------------------------------------------------------

## 1. 设计定位

本模块不是普通的「功能入口区」，而是官网核心业务价值展示区。

核心表达：

> **从标准到培养，从人才到企业，构建产业数字人才完整生态。**

视觉上需要让用户同时理解两件事：

-   左侧：**我们解决什么问题 / 提供什么价值**
-   右侧：**我们通过什么体系解决问题**

因此整体采用：

``` text
业务价值介绍
+
业务能力体系
+
流程关系
+
轻量数据化视觉
```

避免做成传统官网常见的：

``` text
Tab
+
几个白色按钮
+
大面积空白
```

# 27. 设计原则

### 原则一：少而精

不要堆装饰。

### 原则二：体系优先

让用户看到业务之间的关系。

### 原则三：信息优先

装饰不能影响信息阅读。

### 原则四：轻科技

科技感来自：

``` text
渐变
网格
节点
数据
玻璃
空间
```

而不是：

``` text
霓虹
粒子
发光
赛博朋克
```

### 原则五：企业级

整体必须让政府、企业客户感觉：

``` text
专业
可靠
标准化
体系化
```

同时让年轻学员感觉：

``` text
现代
年轻
AI
有活力
```
